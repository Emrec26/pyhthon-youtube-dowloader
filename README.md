# YouTube Video & MP3 Downloader

Bu basit Python aracı, YouTube videolarını en yüksek kalitede video (MP4) veya ses (MP3) olarak bilgisayarınıza indirmenizi sağlar.

##  Kurulum

Çalıştırmak için bilgisayarınızda Python yüklü olmalıdır. Ardından terminale şu komutu yazarak gerekli kütüphaneyi kurun:

```bash
pip install yt-dlp
Not: MP3 (Ses) indirmek istiyorsanız bilgisayarınızda FFmpeg yüklü olmalıdır.

 Kullanım
main.py dosyasını çalıştırın:
python main.py
İndirmek istediğiniz YouTube linkini yapıştırın.
Video için 1, MP3 için 2 yazıp Enter tuşuna basın.
İndirilen dosyalar Indirilen_Medyalar klasörüne kaydedilecektir.
